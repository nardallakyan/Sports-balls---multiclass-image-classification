## 🏈 Описание датасета

Датасет состоит из более чем **9 000 изображений** высокого качества спортивного инвентаря, разбитого на **15 классов**. 

* **Общий объём:** ~421 MB
* **Количество файлов:** ~9 169 изображений
* **Разделение:** 80% — обучающая выборка (`train`), 20% — тестовая выборка (`test`)
* **Очистка данных:** Изображения собраны через Google Images, вручную проверены, а дубликаты удалены с помощью алгоритма perceptual hashing (`dHash`).
* **Особенности:** Наличие визуально сложных и "вводящих в заблуждение" изображений (например, арт-объекты или мячи, раскрашенные под другие виды спорта).
